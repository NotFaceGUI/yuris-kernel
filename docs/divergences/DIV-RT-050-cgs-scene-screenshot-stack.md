## 主人裁决(最高真值,2026-10-24)

### 最终机制

- 弹窗可见背景 = **纱下仍存活/可见的层**:
  - メニュー/セーブ/ロード/コンフィグ系(处理器先调 `ES.SCENARIO.SS` 关场景 UI,
    场景层随之退出可见)⇒ 纱下=窗口基色(黑)=「盖住」;
  - タイトルへ/終了/クイックロード系(不关场景,层交叠共存)⇒ 纱下=活场景暗化=「没盖住」。
- 官方的 CGS 栈层**不参与可见合成**(reserve;幕布 CGS100 的淡入淡出由转场机制承担),
  快照内容只被 CGSCOPY/存档缩略等离屏用途消费。
- 内核的「盖不住」= 我们把 CGS1(COPY2 冻结上一呈现帧, EVID-J3-06)当作
  **最底可见层**渲染:菜单场景层退场后,纱下只剩它 ⇒ 冻结旧屏透出;
  嵌套场景(タイトルへ型)下它还会盖住该透出的活场景。

### 修法(待主人批准)

`COPY2 ID=:/W0/`(主窗口根)产生的 **Snapshot 纹理目标层不参与可见合成**(reserve 层):
- 菜单型:纱下=窗口基色黑 ✓;タイトルへ型:纱下=活场景 ✓ —— 与两图一致;
- `CG[ID=CGS<n> FILE=…]`(资产载入,CG 鉴赏等)不受影响(非 Snapshot);
- 幕布淡入淡出走内核转场机制(主人已确认无恙)不受影响;
- 快照数据仍完整保留供 CGSCOPY/CGSDEL/查询。
- 与被否决的「恒黑」区别:恒黑把层留在合成序里(会盖住活场景),本方案把层
  移出合成序(活场景自然透出)。

### 终版机制(三层证据闭合)

1. **`COPY2 ID=:/W0/` 复制窗口根对象的自有 +0x90 画布 = 全透明空面 (0,0,0,0)**
   (REA `FUN_0042f809`:纯缓冲区 memcpy;根画布从不接收合成内容——主组直绘
   后缓冲 EVID-J3-07;呈现画面截取另有 `CG[DXDRAW=1]/DXBUF` 机制,存档缩略走它)。
   ⇒ CGS 栈层(CGSSS 推入,无后续加工)透明,**不参与可见合成**。
2. **幕布黑化靠 `CGACT[RECTPAINT2 SET=255]`**(CGTSS 在 COPY2 后固定执行,
   官方 trace 三次 CGTSS 全序列证实):RECTPAINT2 = mode 2 **只写 alpha 字节**
   (REA `FUN_0043185c` 行 60-83;内核 `imageop.rs::apply_rect_paint` 早已实现)
   ⇒ 透明面被拉成不透明黑 ⇒ CGTFADEOUT 淡出 = **黑幕布淡出**(「幕布」字面语义)。
   与被否决「恒黑」的本质区别:恒黑把不透明黑留在层里(会盖住交叠场景);
   本方案层本身透明,黑只出现在被 RECTPAINT2 显式拉满的幕布上。
3. **弹窗可见背景 = 纱下仍存活的层**:
   - メニュー系(处理器先 `ES.SCENARIO.SS`;按钮库把全部旧 BT 层 CG[E=0]
