# DIV-012 · V2 RETURNCODE:opcode 按名识别、4 字节行计数、290 的 8 字节

- 状态: **fixed(4 字节形态)/ 待证(290 的 8 字节语义)**
- 优先级: 高(每行文本的行尾让出)
- 发现日期 / 发现方式: 2026-11-17,两套官方语料 + 0.292 `FUN_00437da9`。

## 事实

- 0.292 `ysc.ybn`:`RETURNCODE` 是表序号 **0x38**(56);0.255 是 **0x36**(54)。
  0.292 装载器 `FUN_00437da9` 内部把 0x38 当定长 10 字节,但那只是该
  引擎/该编译器版本的常量;**禁止跨版本硬编码**,必须按工程 `ysc.ybn`
  的命令名识别。
- 两套语料的 `RETURNCODE` 指令都是 `argc=1`,但载荷只有 **4 字节**
  (不是 12 字节窗口)。0.292 的 198 处值域 1..107、0.255 的 179 处
  1..102,逐文件从 1 递增 ⇒ **本脚本内文本行计数**。
- 既有参考实现/计划说 0.290 是 8 字节(含 size);本仓库无 0.290 语料,
  该形态只做结构保留,不声称语义。

## 实现

- `walk_v2` 按 `CommandTable::index_of("RETURNCODE")` 取 opcode;
  `version == 290` 时载荷 8 字节,其余 4 字节。
- 合成 V5 窗口:低 16 位 → `kind/flag`(行 id),高 16 位 → `slot`
  (保留完整 32 位行号),`length=0`(无 V2 证据的 next_voice)。
- 290 的第二个 dword 原样放进 `length`,标注"语义未取证";没有语料
  时不用它做任何判断。

## 验证

- 两套语料全部指令闭合(20,117 / 16,351 条),`RETURNCODE` 计数
  198 / 179,行号值域与递增性在 `corpus_v2` 测试中覆盖;
- 0.292/0.255 headless 跑到标题,文本行尾让出正常。
