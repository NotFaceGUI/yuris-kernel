## 0. 一页结论

1. 自动文本**直接画进 `TEXT[ID]` 目标层的表面**:`TEXT[ID]` 命中后
   `state+0x00 = 层对象 L`;绘制/清屏都经 `L+0x34` 取表面对象 `W`,
   `W+0x78` 宽、`W+0x7c` 高、`W+0x90` 像素。折行用的宽高就是
   **该层表面的宽高**,不存在独立“文本窗口对象”。
2. 折行/禁则算法已逐分支复核,常量表已按 CP932 解码(§3)。
   适配判断里的单元宽**恒为 `SX`**(`+0x40[i] = SX`,半角也不折半);
   `x` 的实际推进是 `FUN_004056b8` 的返回值(GDI 实测 advance)。
3. 逐字符样式快照映射已定:`+0x4c=COLOR、+0x50=COLOR2、
   +0x54=ANTIALIASING、+0x58=GRADATION、+0x5c=BOLD`;绘制时刻还读
   状态级 `+0x33=DRAWMODE`、`+0x34=BNO`。`+0x40=SX、+0x44=SY`。
4. `TEXT[ID]` 未命中是**错误 + 返回 -1**,`state+0x00` 保持旧层不变,
   同一命令后续参数全部跳过;命中时旧层 `W+1=0`、新层 `W+1=1`。
5. `state+0x00 == 0`(从未设 ID 或从未命中)时
   `FUN_00404914` 入口直接返回 ⇒ **没有目标层就没有自动绘制**;
   `DIV-GFX-057` 的“屏幕后置覆盖层”是内核自造行为,不是官方语义。
6. `FUN_004046fc` 复核:手动模式只做“`+0x36` 在位则清待显示缓冲,
   然后恢复”;自动模式在标志游标追上总数时置 `+0x36` 再清缓冲。
   行完成清的是**待显示缓冲**,像素留在层表面 —— 与既有台账一致。
7. `TEXTINFO[CX/CY]` 读 `+0x14/+0x18`,由布局例程推进;内核
   `set_text_cursor` 目前**没有任何调用者**,CX/CY 永不前进。

## 2. `FUN_00404c60` 折行算法(逐分支)

记 `S = state`,`W = *(L+0x34)`,`w = +0x40[游标]`(**恒为 SX**),
`H = W->+0x7c`,`Ww = W->+0x78`,`x = +0x14`,`y = +0x18`。
`hgt[i] = +0x44[i]`。

```text
入口:
  if H <= y + 2 + hgt[i+1]:        # 纵向放不下下一行
      +0x68 = +0x60; return -1     # 文本游标置末尾,调用方不再绘制
  if x + 2 + w >= Ww:              # 本字符都放不下
      x = 0; y += hgt[i]; 纵向检查; return 0
  if x + 2 + 2w < Ww:              # 还剩至少两格
      if Ww <= x + 2 + 4w && flags[i]=='2':
          # 特例:剩余不足四格,当前为全角
          if text[i..i+2] == "！" && flags[i+2]=='2' && text[i+2..i+4] == "？":
              用当前标志的样式连续绘制 "！" 与 "？" 两个字;
              +0x68 += 4; return -1
          if text[i..i+2] ∈ {"「","『","（"}:
              x = 0; y += hgt[i]; 纵向检查      # 行末禁则:移到下一行
          else: return 0                        # 正常绘制
  else:                            # x+2+w < Ww <= x+2+2w:只剩一格
      if flags[i]=='2':
          if text[i..i+2] ∈ 行头禁则集合(§3):
              用当前标志样式绘制该字并 +0x68 += 2;
              return -1                       # 悬挂进右边界
      x = 0; y += hgt[i]; 纵向检查; return 0
```

调用方(`FUN_00404914`)在返回 0 时自行绘制并 `+0x68 += 1/2`;
返回非 0 时**不绘制**、但**仍 `+0x6c += 1`**。

### 2.1 `！？` 特例的游标不对称(必须原样复刻)

特例分支绘制两个字、`+0x68 += 4`,但调用方只 `+0x6c += 1` ⇒
此后 **字节游标与标志游标相差一个字**。这是官方实现事实,不是笔误推断:
- `0x404de6..0x404df4` 检查的是 `flags[+0x6c + 2] == '2'`;
- `0x4054bd..0x405536` 从 `text[+0x68 + 2]` 取第二字;
- 两次绘制都用 `+0x6c` 这一格的样式表(`0x40553b`,不递增索引)。

实现时必须保留两个**独立**游标(`+0x68` / `+0x6c`),不能用
“字符索引 = 字节索引/宽度”反推;否则该特例后的整行像素与官方不同。

## 4. 逐字符样式快照(FONT → 追加 → 绘制)

`FONT` 参数槽(工程 `ysc.ybn`,`probe_cmd_params` 实测):

```text
0 BNO  1 NO  2 NAME  3 ANTIALIASING  4 COLOR  5 COLOR2
6 GRADATION  7 ROTATION  8 DRAWMODE  9 SX  10 SY  11 BOLD
```

写入点(本地反汇编,`0x444380..0x444b20`):

| 状态字段 | 来源参数 | 语义 |
|---|---|---|
| `+0x20` | SX | 单元请求宽 |
| `+0x24` | SY | 单元请求高/行高 |
| `+0x28` | COLOR | 前景色 |
| `+0x2c` | COLOR2 | 背景/渐变终点色 |
| `+0x30` | ANTIALIASING | 每字符快照 → `+0x54` |
| `+0x31` | GRADATION | 每字符快照 → `+0x58` |
| `+0x32` | BOLD | 每字符快照 → `+0x5c` |
| `+0x33` | DRAWMODE | **状态级**,绘制时刻读取(不快照) |
| `+0x34` | BNO | **状态级**,绘制时刻读取(不快照) |

`WORD`/`_` 追加时把 `+0x28/+0x2c/+0x30/+0x31/+0x32` 与 `SX/SY`
按字符下标写入 `+0x4c/+0x50/+0x54/+0x58/+0x5c/+0x40/+0x44`。
`FUN_00404914` 绘制时把 `+0x4c/+0x50/+0x54/+0x58/+0x40/+0x44/+0x5c`
作为每字参数,把状态级 `+0x33/+0x34`(`DRAWMODE/BNO`)与层对象一起传入
`FUN_004056b8`。

## 7. 决策(2026-11-16 主人确认)

1. `！？` 成对禁则的游标不对称:**原样复刻**(像素 1:1 优先)。

## 8. 仍未取证的点

1. **空表面层**:`TEXT[ID]` 命中一个没有基图/尺寸为 0 的层时,
   `W+0x78/0x7c` 的实际值未实测。内核需要把“层存在”和“层可绘制表面”
   分开,不能拿 1×1 占位面当有效宽度。
2. ~~`！？` 特例的游标不对称是否原样复刻~~ —— 已决策:**原样复刻**
   (见 §7)。
3. **`W+1` 标志**(TEXT[ID] 命中置 1、旧层置 0)的消费方未定位;
   不影响本轮布局,登记残余。
4. **与 `CGACT[TEXT]`/图像加工的命令序**(`DIV-GFX-076`):官方文字在
   命令时刻进表面;内核按层绘制时合成。自动层若与 CGACT 混用,顺序仍是
   近似。本轮不扩到 DIV-GFX-076。
5. ~~`TEXT[ID]` 未命中继续执行~~ —— 已修:诊断 `rt.text.layer` +
   `Yield` + 保留旧层,同命令后续参数不再执行。
6. **`'P'` 的层基图**:官方 `zero_fill(W+0x90, w*4*h)` 清整个层表面
   (含基图/图像加工);内核清自动字形 + 同层 `CGACT[TEXT]`,基图保留。
   文本层无基图时等价;有背景图时属 `DIV-GFX-076` 表面模型残余。
7. **同层不同拼写**:`TEXT[ID]` 的换层判断用原始字节;`TX` 与
   `:/W0/TX` 会被当成换层(官方按规范化后的同一层对象)。语料无
   `TEXT[ID]`,登记残余;需要时把探针改为返回规范化层键。
